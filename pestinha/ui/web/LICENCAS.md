# Licenças e créditos da interface web da ilha

- **Núcleo** (`index.html`, `ilha.css`, `ilha.js`): identidade visual e código escritos para o
  Pestinha (orbe neural, molas, trilho de cards, estúdio de som, narrador). A ideia de uma ilha
  no topo da tela é só uma referência de ergonomia; nenhum código, layout, nome, personagem,
  ícone ou som de outros projetos (como o Coucou) é usado.
- **Moxen** (`moxen/centro`, `moxen/parrilla`, `moxen/eslabon`): recursos gratuitos da Moxen
  (moxen.cl/recursos), com licença de uso que permite usar, alterar e incluir em aplicativos.
  Não podem ser redistribuídos como recurso ou modelo. O texto original de cada licença está em
  `moxen/<nome>/LICENCIA.txt`. Os textos da interface foram traduzidos para português.
- O Moxen *Grabadora* serviu apenas como inspiração para o estúdio de som (onda que flui, medidor
  de LEDs, halo que respira); nenhum código dele foi copiado.
